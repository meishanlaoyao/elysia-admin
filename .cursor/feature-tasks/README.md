# feature-tasks (Cursor)

Durable phased task packs for **multi-module / full-project** work in Cursor.

- Protocol: [`.ai/AI_PHASED_TASKS.md`](../../.ai/AI_PHASED_TASKS.md)
- Layout: `{feature-slug}/CHECKLIST.md` + `01-*.md`, `02-*.md`, …
- Not the same as `.cursor/plans/` (ephemeral session plans)

Do not create packs at the repo root.
